# lessons

- `capability` — winit-web `EventLoop::run_app` on wasm throws "Using exceptions for control flow, don't mind me. This isn't actually an error!" as *intended control flow* to unwind the wasm stack after scheduling the async loop; catching it and treating it as boot failure is wrong — success is canvas paint + a live event loop. (Confirmed in winit @ ee245c5 `event_loop/mod.rs` run_app: `elw.run(handler, false)` then `backend::throw`.)
- `capability` — `Backends::all()` in floem-renderer/wgpu on wasm = WebGPU only unless the `webgl` feature is enabled on wgpu; a direct wasm-target dep `wgpu = { version = "24.0.5", features = ["webgl"] }` unifies into floem-renderer's wgpu pin and enables the GLES fallback.
- `capability` — wasm32-unknown-unknown has no libc: tree-sitter C needs wasi-libc + `--allow-undefined`, and the resulting wasm imports `wasi_snapshot_preview1` (7 imports) which `@bjorn3/browser_wasi_shim` + a glue patch can satisfy in-page.
- `artifact` — Lapce dark-theme geometry: `$black = #282C34` = editor.background (primary), `secondary-background = #21252B` = panels/palette/status bar; explorer is LEFT, editor RIGHT in the 800x600 default canvas.
- `artifact` — headless Chrome (any SwiftShader combo tried) exposes no `navigator.gpu`; headed Chrome on macOS does (Metal). S0.3 browser boot therefore requires a headed browser.
- `artifact` — cargo target-dir for this machine is the external SSD (`/Volumes/SSD Samsung/cargo-target` via ~/.cargo/config.toml); it filled twice and OOM'd the machine. Clean stale incremental dirs after big wasm builds.
- `artifact` — canvas does not follow window resize on this floem/winit pin (inline 800px style never updated); recorded as observation for the report, not a gate.
- `capability` — floem's `FONT_SYSTEM` (floem-renderer text layout) maps generic families to concrete names per OS: macOS → "Helvetica Neue", everything else → "Noto Sans"; on wasm with no system fonts every generic SansSerif query misses unless the db override is pointed at a vendored face. cosmic-text's fallback iterator then exhausts and panics at `shape.rs:275` ("no default font found") — the panic is the *requested family had zero matches*, and the fastest way to identify it is to patch the panic message to include family/style/stretch/word.
- `capability` — cosmic-text `Attrs::matches` filters faces by style+stretch only (weight diffs are sorted, never excluding); an italic request with only regular faces yields an empty match set and panics. Vendoring the oblique faces (DejaVu 2.37 ships them) is the fix, not gating the italic styling.
- `artifact` — the S0.3 workbench's file-tree clickable column is x≈35–45 CSS px on the 800x600 canvas (row hit-zone is narrow; x=60/80 miss), and the EXPLORER section header toggle sits at y≈236; pixel-scan row maps (screenshot → band detection → click at x=40) are the reliable driver for headed-browser verification.
- `capability` — Playwright `page.mouse.click` in a headed Chrome on macOS works without OS focus; the winit-web canvas does not need DOM focus for pointer events, but the editor DOES need a real click to take keyboard focus before `page.keyboard.type` lands.
- `capability` — dependency-source edits (git checkout, registry copy, workspace rlib) may not invalidate cargo 1.96 fingerprints; after editing any dependency source, delete the target artifacts (or `rm -rf` the whole target dir) or the build silently links stale code.
- `artifact` — `~/.cargo/registry` + `~/.cargo/git` are symlinked onto the 100%-full SSD: new crate fetches fail when the SSD fills. Workaround: `CARGO_HOME` override to a system-disk dir (used `apps/theorem-ide/.cargo-home`). Combined with the global `target-dir = /Volumes/SSD Samsung/cargo-target`, EVERY cargo invocation on this machine needs `CARGO_TARGET_DIR` + `CARGO_HOME` overrides until the SSD is relieved.
- `capability` — xi-rope `Spans::transform` hard-codes start→`after=false`, end→`after=true`: per-boundary greedy affinity (all four combinations under one delta) is NOT expressible via Spans. Keep the interval tree and transform boundaries through `Transformer` with `after = !greedy_left` for start, `greedy_right` for end. (Resolved by fixtures in d7m.)
- `capability` — `AgentFsHost` (rustyred-thg-agentfs) exposes no subscription channel to store consumers (only FsHostStatus + notify-based file_watcher): the handoff's "watcher → store subscriptions" row is a recorded seam, not an implemented call, and BufferHead-from-graph-history has no per-file head on AgentFsHost. Both are ws-integration work, not proxy-layer gaps.
- `artifact` — Int UI tokens are LIVE in the CommonPlace console: `apps/console/src/styles/int-ui-register.css` (dark) + `int-ui-register-light.css` + `geometry.css` — the dark register declares verbatim Int UI (JetBrains `expUI_dark.theme.json`, SHA 1a82cda). K1's canonical source until the `platform/jewel/int-ui/int-ui-standalone` home exists; `tokens/int-ui.json` is the interim canonicalization.
- `artifact` — the fork's editor text model lives in the floem git dep `floem_editor_core`; `lapce-core` is a 13-line re-export. K8's implementation_mode wording must change (model/view split is NOT inside the fork tree).
- `capability` — floem clipboard on wasm is an upstream TODO ("TODO: Implement clipboard support for the web" in floem's clipboard.rs): copy/paste in the browser is new-machinery (a web-sys adapter behind the existing `Clipboard` trait), a gate-zero item, not inherited behavior.
- `artifact` — `apps/theorem-proxy` in the Theorem repo is the model-path proxy (Anthropic/OpenAI passthrough, SPEC-LOCAL-PROXY-MVP), NOT the IDE proxy: the IDE proxy lives in the fork as `lapce-proxy` with a WorkspaceBackend seam; name collision resolution (rename → `theorem-ide-proxy`) is ws-integration work.
- `artifact` — Lapce stock themes parse to 4 tables / ~165 keys (dark + light both); a generated theme can schema-MATCH stock defaults key-for-key with token-driven decisions (hues, status, heights 40/28/13). The fork scans the user data-dir themes/, NOT the repo `themes/` dir — activation wiring is styling-wave work.
